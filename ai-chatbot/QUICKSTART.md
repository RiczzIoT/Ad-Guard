# Quick Start Guide

## 🚀 Get Started in 3 Steps

### 1. Navigate to the project
```bash
cd /vercel/sandbox/ai-chatbot
```

### 2. Run the development server
```bash
npm run dev
```

### 3. Open your browser
Visit: **http://localhost:3000**

---

## 🎯 What You'll See

- A beautiful chat interface with a gradient background
- An AI assistant ready to chat
- Real-time message responses
- Smooth animations and typing indicators

## 💡 Try These Commands

Type these messages to see different responses:
- "Hello" or "Hi"
- "What can you do?"
- "Who are you?"
- "Help"
- Ask any question!

## 🛠️ Available Scripts

```bash
npm run dev      # Start development server
npm run build    # Create production build
npm start        # Run production server
npm run lint     # Run ESLint
```

## 📝 Key Features

✅ Modern Next.js 16 with App Router

✅ Tailwind CSS for styling

✅ AI-powered responses

## 🔧 Customization

Want to connect to a real AI service like OpenAI?

1. Get an API key from OpenAI
2. Create `.env.local` file:
   ```
   OPENAI_API_KEY=your_key_here
   ```
3. Modify `app/api/chat/route.ts` to use the OpenAI API

See the main README.md for detailed instructions!
